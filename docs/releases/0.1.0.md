# Codex Retain 0.1.0

First public release: configurable retention for archived local Codex chats,
with preview, exclusions, pause/resume, and hourly macOS scheduling.

## Install

macOS 15 or later, Apple Silicon or Intel; no Rust runtime required:

```sh
curl -fsSL https://github.com/Dankosik/codex-retain/releases/download/0.1.0/install.sh -o /tmp/codex-retain-install.sh
CODEX_RETAIN_VERSION=0.1.0 sh /tmp/codex-retain-install.sh
```

The installer checks SHA-256 and installs to `~/.local/bin`. Add that directory
to PATH, then run `codex-retain doctor`. Installation does not enable cleanup.
Rerun the latest release's installer to update at the same path.

Homebrew instructions and source installation are in the
[README](https://github.com/Dankosik/codex-retain#quick-start).
Archives include licenses; `SHA256SUMS` covers both architecture archives.

## Compatibility

The storage adapter supports Codex CLI 0.153.4 local legacy history. Codex
Desktop's embedded server is not certified by a separate installed CLI version.
Spawn-related and paginated/shared histories are skipped. Linux is experimental
for core/preview; destructive operations and scheduling are macOS-only.
Binaries are not Developer ID signed or notarized.

Deletion is permanent once explicitly enabled with `--yes`. Existing archives
receive a fresh full grace period. Review compatibility and preview before
relying on automatic cleanup.
