# Codex Retain

Утилита удаляет подходящие локальные архивированные чаты Codex после выбранного
срока. На macOS её раз в час запускает `launchd`; постоянно работающего процесса,
облака, аккаунта и LLM у самой утилиты нет.

Версия 0.1 проверена для **Codex CLI 0.153.4**, его локальной базы `state_5.sqlite`
и обычных JSONL/zstd-переписок. Версия CLI из PATH не доказывает совместимость
встроенного сервера приложения Codex: все клиенты выбранного профиля должны
использовать поддерживаемую версию. Связанные и paginated-переписки пропускаются.

Из этого каталога проекта:

```sh
cargo install --path . --locked
codex-retain enable --days 30 --yes
```

Первая команда собирает и устанавливает бинарник. Вторая осознанно включает
политику и почасовой запуск. **Уже накопившийся архив получает полные 30 дней
отсрочки; при включении ничего не удаляется.** Вместо 30 можно выбрать 7 или
другой целый срок в днях. После включения обычные запуски подтверждений не требуют.

| Что нужно | Команда |
| --- | --- |
| Узнать состояние | `codex-retain status` |
| Посмотреть кандидатов и причины пропуска | `codex-retain preview` |
| Очистить сейчас по действующей политике | `codex-retain run` |
| Приостановить удаление | `codex-retain pause` |
| Продолжить | `codex-retain resume` |
| Увеличить срок | `codex-retain policy --days 60` |
| Осознанно сократить срок | `codex-retain policy --days 7 --yes` |
| Защитить важный чат | `codex-retain exclude UUID_ЧАТА` |
| Полностью отключить очистку | `codex-retain disable` |
| Подготовить удаление программы | `codex-retain uninstall` |

Время отсчитывается по переходам в архив, записанным в небольшой таблице SQLite
в той же транзакции, что и изменение статуса Codex. Восстановление убирает этот
срок, повторное архивирование начинает новый. Работающий в фоне процесс для
наблюдения не нужен. Ремонт индекса, меняющий время архивирования, консервативно
даёт новый срок; `mtime` файла не используется для решения об удалении.

Пауза останавливает удаление, но время нахождения в архиве продолжает идти.
После возобновления давно архивированные чаты могут стать кандидатами сразу.
Нативные закрепления Codex и явные исключения защищены. Активные, неоднозначные,
занятые и неподдерживаемые переписки не удаляются.

Очищаются конкретные локальные rollout-файлы и строки выбранных чатов в базе.
Облачная история, общие индексы, логи, отдельные базы памяти, снимки диска и все
следы переписки не входят в это обещание. Отчёт отдельно показывает длину файлов,
оценку удалённых блоков и наблюдаемое изменение свободного места. Точное число
физически освобождённых байт на APFS надёжно приписать утилите невозможно.

Перед удалением установленного через Cargo бинарника:

```sh
codex-retain uninstall
cargo uninstall codex-retain
```

Первый шаг отключает политику, убирает LaunchAgent и журнал переходов. Скрытой
копии исполняемого файла нет. Если данные Codex временно недоступны, программа
сообщит о незавершённом шаге; политику она отключает в первую очередь.
